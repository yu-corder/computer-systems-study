・レジスタ
DFFを用いて実装

・メモリ
複数のレジスタを重ねる

レジスタとメモリの違い
|         | レジスタ         | RAM        |
| ------- | ------------ | ---------- |
| 場所      | CPU内部        | CPUの外部が一般的 |
| 速度      | 非常に高速        | レジスタより遅い   |
| 容量      | 非常に小さい       | 大きい        |
| 主な用途    | 計算中の値・CPUの状態 | プログラム・データ  |
| CPUとの距離 | 非常に近い        | CPUより遠い    |

クロック周期について
クロック周波数を上がれば、書き込み速度などが向上するが、同時に遅延についても考慮する必要あり
